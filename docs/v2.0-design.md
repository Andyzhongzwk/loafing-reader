# v2.0 Design — "Read Well" (读得好)

Status: draft, agreed direction 2026-09-21.
Scope: the P0 batch from the UX audit. Loading/encoding improvements and
chapter detection are deliberately deferred to a later release (see Roadmap).

## Goals

1. Reading quality: user-controlled typography (size, line-height, font, opacity).
2. Navigation: keyboard support, percentage-based progress, scroll mode.
3. Correctness: fix the known bugs listed in CHANGELOG 1.3.0.
4. Zero modal dialogs: no `alert()` / `prompt()` anywhere.

## Non-goals (this release)

- Encoding auto-detection, chapter detection → next release ("load well").
- Boss key, disguise skins → v2.2 ("hide well").
- Real drag/resize replacing the `[移动]` toggle → v2.1 ("move well").

## Feature spec

### 1. Settings panel (⚙ button in toolbar)

Inline popover, all values persisted to a single versioned JSON key
`lf_settings` via GM_setValue:

| Setting | Range | Default |
|---|---|---|
| font size | 12–24 px slider | 12 |
| line height | 1.2–2.0 slider | 1.5 |
| font family | serif / sans-serif / 仿宋 | sans-serif |
| text opacity | 50–100 % | 100 |
| background opacity | 0–40 % | current look |
| reading mode | page / scroll | page |

Changes apply live to the panel (no reload). First-run defaults reproduce the
v1.3 look.

### 2. Reading modes

- **Page mode** (default): current behavior — click to page.
- **Scroll mode**: continuous scroll inside `#lf-content`; a 2px progress bar
  on the right edge of the panel, draggable; status line shows
  `《书名》 · 34.7% · 第 4,213 行`.

### 3. Navigation

- Keyboard (scoped to the panel while visible; never global):
  `→`/`Space` next page, `←` previous, `↑`/`↓` or wheel scroll in scroll
  mode, `[` / `]` font size, `Esc` hide panel.
- Jump popover replaces `prompt()`: percentage input pre-filled with current
  position, quick actions `开头` / `上次位置` / `末尾`.

### 4. Feedback

- Toast component at panel bottom, auto-dismiss after ~1.5s. Replaces all
  `alert()` calls ("已是最后一页", "输入有误" etc.).

### 5. Bug fixes (from CHANGELOG known issues)

- CSS trailing comma in `#lf-text`.
- `textContent` instead of `innerHTML` for book content.
- Scoped `addEventListener` instead of `document.onkeydown =` (page shortcut
  canary in tests/test.html must stay green).
- z-index raised above common site chrome (test against the sticky header).
- Consecutive blank lines collapsed to one.
- Files > ~5 MB: skip GM persistence, toast a warning; reading still works.

## Acceptance checks

- `npm test` green (extend smoke.js for settings persistence, blank-line
  collapsing, scroll mode).
- tests/test.html checklist passes manually, including the shortcut canary.
- Refresh → Alt+R restores book, position, and settings.
